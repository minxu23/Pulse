# Pulse 医生审阅清单

这份清单列出 Pulse 里所有会影响用户健康决定的规则和数字：什么时候提醒联系医生，运动怎么限强度，目标怎么定。每条写明 Pulse 现在的做法和依据，请在最后一列写下意见。详细的推导和参考文献见《三阶段健康计划设计》（同一文件夹）。

## 1. 需要立即处理或尽快就医的提醒

这些提醒会显示在「今日」，打开「异常提醒」后也会推送通知（健康 App 有新的血压、血糖、体重时会立即检查）。Pulse 每次都提示：不能代替急救。

| 情况 | Pulse 的做法 | 依据 | 意见 |
|---|---|---|---|
| 血压 ≥ 180/120 mmHg（单次） | 「请尽快处理」：坐 5 分钟后复测；仍很高且有胸痛、气短、肢体无力、视物模糊、说话困难，立即拨打 120；没有症状也尽快联系医生 | ESC 2020；《中国高血压防治指南（2024 年修订版）》 | |
| 有症状时收缩压 < 90 | 建议联系医生 | | |
| 近期血压平均 ≥ 140/90（最近 3–5 次） | 建议联系医生 | 同上 | |
| 有心血管情况，血压高于医生定的目标 | 提醒核对 | 用户填的目标 | |
| 血糖 < 3.0 mmol/L | 「请尽快处理」 | ADA 2026 二级低血糖 | |
| 血糖低于用户设定的下限（默认 3.9） | 提醒核对 | ADA 2026 | |
| 血糖 > 13.9 mmol/L | 建议联系医生；1 型糖尿病按医嘱查酮体，酮体阳性或恶心、呕吐、腹痛时不运动并尽快就医 | 《中国 2 型糖尿病运动治疗指南（2024 版）》 | |
| 清醒时血氧 < 92%（< 88% 为紧急） | 建议联系医生 | | |
| 近一周有 2 晚以上夜间血氧最低 < 88% | 提醒核对，建议评估睡眠呼吸 | | |
| 静息心率近 3 次有 2 次 > 100 | 建议联系医生 | 成人静息心率 60–100 | |
| 静息心率近 3 次有 2 次 < 40（服控制心率药物时 < 50），运动员除外 | 建议联系医生 | | |
| 静息心率连续 3 天比前 4 周平均高 ≥ 7（或 2 倍个人标准差） | 提示可能是生病、疲劳或饮酒，减量 | | |
| 慢性肾病、心衰、限水或腹膜透析的用户，3 天内体重增加 ≥ 2 kg（血液透析不在此列） | 建议复称、看浮肿，仍偏高就联系医生；不要自己调整利尿剂；休息时也气短、躺下更喘立即就医 | 心衰指南常用阈值 | |
| 体温 ≥ 38 ℃ | 暂停训练，多休息、补水；高热不退或有胸痛、气短就医 | | |
| 血钾 < 3.0 或 ≥ 6.0 mmol/L | 「请尽快处理」 | | |
| eGFR < 15 | 建议尽快联系肾内科 | KDIGO | |
| eGFR 比上次下降 ≥ 25% | 建议尽快把结果给医生看，不要自己停药或加药 | KDIGO | |

## 2. 开始改善方案前要先看医生的情况

有下面任何一条，Pulse 先只开放基础层（步数、少坐、睡眠、每周 2 次力量），等用户确认「医生已看过」后才开始方案。这个确认只用来开始方案，不会解除下面第 3 节的强度上限。

| 情况 | 意见 |
|---|---|
| PAR-Q+ 任何一题回答「是」 | |
| 运动时胸痛、胸闷、晕厥、不明原因的气短 | |
| 手表的不规则心律通知，或有房颤负荷 | |
| 家庭血压平均 ≥ 160/100 | |
| 静息心率持续 > 100，或 < 40 且有不适 | |
| 糖尿病用户频繁低于 3.0 mmol/L | |

睡眠方案另外两条（见第 5 节）：夜间呼吸线索多或疑似睡眠呼吸暂停，以及已确诊但还没治疗的睡眠呼吸暂停，要先看医生。

## 3. 运动强度

| 规则 | Pulse 的做法 | 依据 | 意见 |
|---|---|---|---|
| 最大心率 | 208 − 0.7 × 年龄；基线期实测更高（且不超过公式 + 15）就用实测值；没填年龄就不给心率数字，只用说话测试 | Tanaka 2001 | |
| 心率区间 | 心率储备法：中等 40–59%，较高 60–89% | ACSM（Garber 2011） | |
| 服 β 受体阻滞剂等控制心率的药 | 不用心率区间，改用主观用力程度和说话测试 | | |
| 医生给的心率上限 | 优先于所有公式；超过时当天提醒 | | |
| 心血管情况没有医生确认、妊娠、心衰、有强度上限 | 不安排高强度间歇，核心训练改成中等强度 | | |
| 近 30 天平均血压 ≥ 160/100 | 不做大重量力量和憋气用力；≥ 140/90 时做力量要保持呼吸、不冲极限重量。设计文档另有「收缩压 > 160 不做高强度」，App 里目前只落实在力量训练上 | ESC 2020 | |
| 等长练习（靠墙静蹲 2 分钟 × 4 组） | 膝关节问题、65 岁以上、冠心病、心衰、心律失常改成静力握拳；全程不憋气 | Edwards 2023、2024 | |
| 65 岁以上 | 间歇改成「快走 1 分钟、慢走 2 分钟」；每周 3 次平衡练习 | WHO 2020；世界跌倒预防指南 2022 | |
| 用胰岛素或磺脲类 | 运动前血糖 < 5.6 先吃碳水，随身带糖；饭后约 1 小时再运动 | 《中国 2 型糖尿病运动治疗指南（2024 版）》 | |
| 增殖期视网膜病变 | 设计文档写了「不做剧烈运动和力量训练」，但 App 里还没有记录视网膜病变的地方，这条目前没有落实 | ADA 2026 | |
| 透析日 | 不安排训练 | | |
| 加量 | 每周总量增加不超过约 10%；完成 < 60% 下周减约 15% | | |

## 4. 各方案的 4 周目标

目标定在 4 周能变化、又超过测量本身波动的范围。没达到不算失败，下一轮按完成情况调整；连续 3 轮没达到，血压、血糖、睡眠的方案会建议带着记录去看医生。

| 主靶点 | 4 周目标 | 依据 | 意见 |
|---|---|---|---|
| 家庭血压（7 天平均） | 收缩压降 5，或降到医生的目标（有高血压）/ 135 以下（没有高血压），取先达到的；已经达标的保持 | Lea 2024；Cornelissen 2013 | |
| 诊所或药店的血压 | 降 10 或到目标；要求每周都有读数 | Stergiou 2002 | |
| 静息心率 | 起点 ≥ 70 降 3，否则降 2 | Reimers 2018 | |
| 最大摄氧量 | 提高 5%（至少 1.5）；已在同龄前 25% 的提高 3% | Milanović 2015 | |
| 体重 | 7 天平均降 2% | ADA 2026 | |
| CGM 血糖达标时间（糖尿病） | 提高 5 个百分点，最多到 70% | Battelino 2019 | |
| CGM 高于 7.8 的时间（无糖尿病） | 减少三分之一，或降到 60 岁以下 3.9%、60 岁以上 8.6% 以内 | Shah 2019 | |
| 空腹血糖 | 降 0.5，不低于 5.6（糖尿病 6.5） | | |
| 睡眠时长（7 晚平均） | 多睡半小时，最多到 7 小时；月末看第 3–4 周的平均 | 延长睡眠试验 +21–51 分钟（Zhu 2022） | |
| 入睡时间波动（7 晚的标准差） | 少 20 分钟，最低到 30 分钟 | 没有找到提高作息规律的成人试验，是 Pulse 的取舍 | |

## 5. 睡眠方案（新增）

| 规则 | Pulse 的做法 | 意见 |
|---|---|---|
| 适合谁 | 平均每晚睡不到 7 小时，或入睡时间每天相差超过 60 分钟（60 分钟是 Pulse 的取舍；MESA 里 > 90 分钟心血管风险约翻倍） | |
| 不适合 | 倒班（作息跟排班走）；夜间呼吸线索多、STOP-BANG ≥ 5 分、疑似或已确诊但未治疗的睡眠呼吸暂停：先看医生。3–4 分不单独拦（特异度低） | |
| 核心做法 | 起床时间固定（周末不晚于平时 1 小时）；睡得少的，上床时间每周提前 15 分钟，直到睡够 7 小时；躺下 20 分钟睡不着就起来，困了再回床（65 岁以上或关节不好的提醒防跌倒） | |
| 习惯 | 下午（默认 14 点）后不喝咖啡和功能饮料；晚上尽量不喝酒；小睡不超过 30 分钟；早上接触亮光，晚上调暗灯光；高强度运动在睡前 1 小时以前结束 | |
| 失眠 | 每周至少 3 晚入睡或维持睡眠困难、持续 3 个月以上：提示可能是失眠，这时先别再提前上床，首选失眠认知行为治疗（CBT-I），请去睡眠门诊。Pulse 没有失眠的诊断字段，只能在计划里提示；也不做睡眠限制疗法 | |
| 每周检查 | 每周至少 5 天在固定时间前后半小时内醒来，至少 5 晚按时睡着（按手表记录的入睡时间）。一周平均比基线多 45 分钟以上才说「真的在变好」 | |

## 6. Health Agent 的回答边界

| 规则 | 意见 |
|---|---|
| 训练建议、能不能练，来自规则和当时的数据，不让语言模型自己判断 | |
| 血压、血糖的走势预测只说范围，每次都注明「不能据此调整药量」 | |
| 症状类问题照搬写好的规则答案，结尾有就医提示；胸痛、晕厥、呼吸困难等直接建议急救 | |
| 不建议用户自己开始、停用或调整任何药物 | |
