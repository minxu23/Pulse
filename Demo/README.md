# Pulse 演示

不需要打开 Xcode 或 Claude Code，双击即可在 iOS 模拟器中演示 Pulse。

| 文件 | 作用 |
|---|---|
| **启动演示.command** | 启动模拟器并打开 Pulse，选择一位示例用户（晓林 / 陈杰 / 林悦 / 王建国各 120 天；孙浩 / 周敏 / 赵立强 / 何静各一整年），载入全新的数据 |
| **继续演示.command** | 打开 Pulse，保留上次演示中记录或修改的数据 |
| **更新演示应用.command** | 修改代码后，从源代码重新构建 `Pulse.app` |
| `Pulse.app` | 预先构建好的模拟器版 App（Release，同时支持 Apple 芯片与 Intel Mac） |

## 使用

1. 双击 **启动演示.command**。第一次运行如果提示「无法验证开发者」，请右键点按 → 打开。
2. 脚本会把这次的 Pulse 装到所有已经开着的 iPhone 模拟器上并打开（都没开时在最新的 iOS 版本上启动 iPhone 17），所以模拟器窗口里显示的不会是旧版本。
3. 模拟器窗口：
   - Xcode 26 及更早版本会打开 **Simulator**。
   - Xcode 27 会打开 **DeviceHub**，在左侧选择脚本提示的任意一台 iPhone 即可看到并操作 App。

## 示例用户

运行「启动演示」时，在终端窗口输入 1–8 选择（10 秒内不选则用晓林），也可以 `PULSE_PERSONA=chenjie ./启动演示.command`：

1. **晓林**：坚持得不错，静息心率明显下降。
2. **陈杰**：久坐、血压偏高、熬夜饮酒，计划常落空。
3. **林悦**：倒班护士，作息混乱，记录断断续续。
4. **王建国**：2 型糖尿病与高血压，漏服药、运动少。
5. **孙浩**（`sunhao`）：重度睡眠呼吸暂停，8 个月前开始用呼吸机，静息心率、血压和体重慢慢下来。
6. **周敏**（`zhoumin`）：血液透析（周一三五），限水，周末后体重常涨多，每月化验血钾、血磷。
7. **赵立强**（`zhaoliqiang`）：心梗放支架后心衰，吃 β 受体阻滞剂，每天称体重，坚持心脏康复。
8. **何静**（`hejing`）：1 型糖尿病，练半马，最近一个月戴 CGM，跑步后夜里偶有低血糖。

前四位各有 120 天的记录；陈杰、林悦、王建国健康情况一般、遵从性差，适合演示复盘中的「Agent 的建议」、下周计划和 Health Agent 如何应对。后四位各有一整年的记录，适合看「趋势」的 1 年范围、长期复盘，以及透析、限水、呼吸机、1 型糖尿病这些照护功能。App 中也可以在「我的 › 示例用户」随时切换。

## 需要

- 安装了 Xcode 的 Mac（含 iOS 18 或更新的模拟器运行环境）。
- 如果 `Pulse.app` 不存在或无法安装，脚本会自动从源代码构建（约 1–2 分钟）。

## 演示建议

- **今日**：身体准备度、静息心率，点「全天安排」中的阶段卡片进入晨起评估、运动、饮食与指标、睡前、全天回顾。
- **趋势**：静息心率趋势、关键指标（CGM 连续血糖曲线 → 血糖管理）、异常跟进。
- **复盘**：Health Agent 的本周结论、可一键采纳的建议、三问复盘、根据复盘生成下周计划；底部可以打字或语音提问。
- **我的**：专业支持（专项运动、心血管健康、血糖管理）、云端模型（测试）。

## 云端模型（OpenRouter / Anthropic）

启动脚本会读取 `~/.spark/keys/openrouter.key` 和 `~/.spark/keys/anthropic.key`（与 Spark、summit2md 共用的密钥），只在本次运行中传给 App：不会显示、复制或写入任何文件。在 App「我的 › 云端模型（测试）」中：

1. 服务默认是 **OpenRouter**，模型默认 **Claude Sonnet 5.5**（可在菜单中切换，或「浏览全部模型」）。
2. 点「测试连接」（只发送一句固定文字）。
3. 打开「我了解提问时会发送数据摘要」，再打开「使用云端模型回答」。

不想带上密钥时，在终端用 `PULSE_NO_CLOUD_KEYS=1` 运行脚本；密钥放在其他目录时用 `PULSE_KEY_DIR=/路径` 指定。

说明：未启用云端模型时，Health Agent 在 Apple 智能可用的 Mac 上由设备端模型回答，否则使用本机规则分析。「启动演示」会重置这些模拟器中 Pulse 的数据。
